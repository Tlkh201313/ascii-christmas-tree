# ASCII Christmas Tree

An animated ASCII Christmas tree on one canvas. Everything on screen is a text character; sound is synthesised with Web Audio plus a backing track.

- Live countdown to Christmas in the visitor's own time zone (hover or tap the timer for the flip effect).
- After the 12-second intro: drag to spin, tap the tree to hang ornaments (saved in the browser), tap the sky for fireworks, tap the star, gifts, deer and moon.
- Works on desktop and phone. Keys: Space pause, M mute, C clear ornaments, R replay.

Edit `src/christmas-tree.src.html`, then run `node build.mjs [song.mp3]` to regenerate `index.html`.
